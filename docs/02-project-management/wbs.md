# Work Breakdown Structure (WBS)

**Project:** Rural Water Point Functionality Prediction Using Machine Learning
**Module:** Software Engineering – 351 CS 3201

| WBS ID | Work package | Main activities | Deliverable |
|---|---|---|---|
| 1.0 | Project management | Define scope, schedule, budget and risks | Project plan |
| 1.1 | Baseline assessment | Inspect existing application, database and Git history | As-built assessment |
| 1.2 | Requirements engineering | Identify users, functional and non-functional requirements | SRS and traceability matrix |
| 1.3 | Stakeholder elicitation | Conduct and document genuine stakeholder sessions | Elicitation report |
| 2.0 | System analysis and design | Define architecture, data flow and interfaces | Design dossier |
| 2.1 | Database design | Define entities, relationships and constraints | ERD and schema |
| 2.2 | UML modelling | Prepare use-case, class and sequence diagrams | UML diagrams |
| 2.3 | Architecture design | Document components and deployment | Architecture diagrams |
| 3.0 | Application development | Improve Flask application and role permissions | Working application |
| 3.1 | User management | Implement secure user administration | User management module |
| 3.2 | Borehole management | Implement borehole records and inspection workflows | Borehole module |
| 3.3 | Maintenance management | Record repair work and progress | Maintenance module |
| 3.4 | Risk prediction | Train and integrate the machine-learning model | Prediction module |
| 3.5 | Decision support | Rank maintenance priorities and explain risk | Priority dashboard |
| 4.0 | Data engineering | Validate, clean and document field records | Data-quality report |
| 4.1 | Model evaluation | Implement backtesting and baseline comparison | Evaluation report |
| 4.2 | Uncertainty evaluation | Assess calibration and prediction-set coverage | Uncertainty report |
| 5.0 | Software testing | Perform unit, integration and functional testing | Test report |
| 5.1 | Security testing | Check authentication and role restrictions | Security test evidence |
| 5.2 | Performance testing | Measure dashboard and scoring performance | Performance report |
| 6.0 | Quality assurance | Review code, documentation and standards | QA dossier |
| 7.0 | Release preparation | Prepare user guide, operations guide and release evidence | Version 1.0.0 package |
| 8.0 | Demonstration and submission | Prepare presentation, demonstration and reflection | Final submission |

## WBS completion note

This WBS identifies the planned work packages. A task should only be marked complete after its output has been produced and verified.
